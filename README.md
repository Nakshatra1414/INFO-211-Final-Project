# INFO-211-Final-Project
# Online Retail Business Intelligence Project

## Overview

This project analyzes an online retail transaction dataset using data analysis and machine learning techniques to uncover actionable business insights.

The project focuses on customer behavior, sales trends, and product relationships to help businesses improve marketing, inventory planning, and revenue generation.

---

## Objectives

* Understand customer purchasing patterns
* Classify customers into value-based categories
* Group customers using clustering
* Predict transaction values
* Discover products frequently bought together

---

## Dataset

Online Retail Transaction Dataset containing:

* InvoiceNo
* StockCode
* Description
* Quantity
* InvoiceDate
* UnitPrice
* CustomerID
* Country

---

## Methods Used

### Data Cleaning

Prepared the dataset by removing invalid and missing entries.

---

### Exploratory Data Analysis

Identified sales trends, top products, and revenue sources.

---

### Machine Learning Models

#### Regression

Used to predict transaction value.

Models:

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor

---

#### Classification

Used to categorize customers into low, medium, and high-value groups.

Models:

* Logistic Regression
* KNN
* Random Forest Classifier

---

#### Clustering

Used to group customers based on purchasing behavior.

Models:

* K-Means
* Hierarchical Clustering

---

### Market Basket Analysis

Used Apriori and association rules to identify products frequently purchased together.

---

## Key Results

* Customer classification achieved **88% accuracy**
* Spending prediction had limited reliability (**R² = 0.13**)
* Market Basket Analysis revealed strong product pairings with **lift values above 24**

The project provides recommendations for:
